### Über uns

BlazonUI baut Addons für World of Warcraft und eine deutschsprachige Community, die
sie gemeinsam weiterentwickelt. Wir konzentrieren uns auf Blizzards Retail- und
Classic-Realms — sauber entwickelt, offen dokumentiert und langfristig gepflegt.

- 🐞 Bug-Reports und 💡 Feature-Vorschläge laufen offen über Discord & GitHub Issues
- 🗺️ Öffentliche Roadmap, von der Community mitpriorisiert
- 🤝 Jeder kann mitlesen, mitdenken, mitbauen
